# Programación 1
Este repositorio contiene los programas y ejercicios
desarrollados durante la materia de Programación 1.
Los ejercicios están organizados por temas, y cada
programa se encuentra en su propia carpeta.
## Programas incluidos
### BlackJack
Juego para dos participantes con un objetivo de acumular 21 puntos en las cartas
### Contraseña
Verifica que una contraseña sea segura, revisando que contenga simbolos,nùmeros y mayusculas
### ListaSinRepetir
Verifica que las personas o el contenido de la lista no se repita
